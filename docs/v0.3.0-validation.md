## Packaged UI acceptance

Use a separate bundle identifier for a preview copy, so automation never selects the installed app. Preview data are invented, generated by `scripts/make_v03_preview.py`; the preview disables automatic scans, quota network requests, publication and project backfill.

```bash
python3 scripts/make_v03_preview.py /tmp/tt-preview-new
TT_UI_PREVIEW=1 TT_UI_TEST_SHOW_MAIN=1 TOKENTRACKER_DB=/tmp/tt-preview-new/usage.db \
  dist/TokenTracker.app/Contents/MacOS/TokenTracker
```

Optional preview-only appearance flags: `TT_UI_PREVIEW_DARK=1`, `TT_UI_PREVIEW_NARROW=1`.
