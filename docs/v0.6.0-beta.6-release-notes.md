测试版：概览配额卡片可自由摆放，同一账号的多把 API Key 合并展示，Antigravity 会话自动归属项目，并精简概览页。

- **概览配额卡片位置可调**：在配额卡片右上角或「设置 › 外观与状态栏 › 概览」切换为主图右侧（默认）/ 主图左侧 / 页面顶部 / 页面底部 / 不显示；页面顶部与底部时按窗口宽度多列排布，侧栏最多显示 8 个账号，其余以「还有 N 个账号」入口进入账号页。
- **同一账号的多把 API Key 合并展示**：DeepSeek 等只返回余额、不返回账号 ID 的供应商，若多把 Key 查询到的官方余额完全一致且非零，在账号页、概览配额卡片与菜单栏面板中合并为一行（「API Key ····xxxx 等 3 把」）；账号详情逐把列出来源并可单独移除，存储与查询仍按 Key 独立。
- **Antigravity 会话自动归属项目**：无需安装 Hook，扫描时只读 Antigravity 自带的 `conversation_summaries.db`（仅 `conversation_id` 与 `workspace_uris` 两列，不读标题、预览或正文）解析会话工作区；已安装 Hook 时以 Hook 记录为准。升级后首次扫描自动回填已扫描会话的项目归属，「用量 → 项目」即可看到 Antigravity 的项目分布。
- **精简概览**：移除概览底部「数据与风险」卡片；数据健康仍可从顶栏扫描状态打开。
