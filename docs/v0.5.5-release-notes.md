热力图新增日、周、月、年、自选和全部时间范围，修复悬停卡顿与重复查询历史用量的问题。

- 使用独立查询队列、数据库版本缓存和原生网格绘制。鼠标悬停仅更新选中格与明细，切换概览范围不再重复汇总全部历史。
- 日视图按小时展示；周视图按周一至周日，月和年按自然月、自然年。支持前后翻页、日期选择与回到今天，自选范围包含开始和结束日期。
- 全部历史与较长自选范围自动按月或年汇总，控制格子数量；保留所有 Agent 的 Token 合计、活跃日、悬停／点击明细和方向键浏览。
- 本地夏令时日期支持 23／25 个独立小时。跨小时观察区间保留当日说明，不均摊到小时；无法定位到天的历史用量单独说明。空白与无记录继续区分。
- 快速切换时仅展示最终范围的结果，数据库变化后自动刷新缓存，读取失败可直接重试。

热力图仅在本机展示。未修改数据库格式、扫描去重规则或公开上传字段。

macOS 安装包采用 ad-hoc 签名，未公证。
