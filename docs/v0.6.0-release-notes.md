正式版：汇总 0.6.0 全部测试版。主窗口改为顶栏导航，新增本机端口页与 Antigravity 支持，用量与概览补齐图表，状态栏新增三种样式，计价覆盖更多来源与模型。

本版新增（相对 0.6.0-beta.6）：

- **状态栏三种样式**：原生单色（进度环内嵌平台字母，仅预警时上色）、双行仪表（上行今日 Token，下行平台与百分比，竖条表示配额）、配额胶囊（品牌色头像与按用量填充的胶囊）。在「设置 › 外观与状态栏」带预览切换，或右键状态栏图标切换。
- **计价覆盖更广**：原名无精确价时，依次尝试去掉转发前缀、已知来源别名（如 `deepseek-v4.1-flash` → `deepseek-flash`）与推理强度后缀（`-low` / `-high` / `-xhigh` 等）后再精确匹配；早于模型首个价格版本的事件按首个官方价回溯估算。价格源新增 Google Gemini 与 MiniMax。仍不使用默认价或子串匹配，细节见 `docs/metrics.md`。
- **账号登录凭证说明**：账号详情显示 TokenTracker 自己保存的登录凭证有效期，以及能否在到期前自动续期；查询失败的快照标为「未能刷新」。
- **万 / 亿显示**：中文「亿」模式在 1 亿以下改用万（如 4412万），状态栏与主窗口一致。

0.6.0 测试版累计：

- **顶栏导航主窗口**：概览、用量、端口、活动、报告、账号六个主视图（⌘1–⌘6），共用时间范围与 Agent 筛选；设置收拢为 5 类。
- **本机端口**：扫描监听端口，区分仅本机与局域网可达，显示内存占用、命令行与开发框架并归属到项目；支持搜索、固定到状态栏、浏览器打开、启停与确认后关闭进程。端口信息只在内存中。
- **Antigravity**：扫描对话日志统计用量，会话自动归属项目，只读识别本机登录态显示配额，并接入任务提醒。
- **用量图表**：项目、模型、会话三个视图配齐占比环形图、Token 构成与缓存命中率图表；会话显示完整元数据、执行时间线与源文件定位。
- **概览**：今天的实时脉冲面板，今天 / 近 7 天 / 本月 / 全部 各自的 Token 热力图，配额卡片位置可调，同一账号的多把 API Key 合并展示。
- **活动与周报**：活动解析 v3 校准执行状态与耗时；周报按自然周去重（schema v8，升级前自动备份）。
- **应用内更新**：设置中可打开「接收测试版更新」；测试版用户会正常收到本正式版。

数据库为 schema v8，v0.5.9 及更早版本无法打开升级后的数据库。未修改扫描去重规则或公开上传字段。

macOS 安装包采用 ad-hoc 签名，未公证。
