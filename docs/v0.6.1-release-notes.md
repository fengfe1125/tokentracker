正式版：会话新增「对话」预览，可直接查看本机会话都聊了什么，并导出为 Markdown。

- **会话对话预览**：会话详情新增「对话」分页（也可在会话列表右键「查看对话」），按需读取本机原始日志，还原你的提问、助手回复、工具调用与结果；工具调用折叠为一行摘要，点开查看参数与输出，出错的调用会标红。「思考」与「系统注入」默认隐藏，可一键打开；支持在对话中搜索、跳到开头或末尾。
- **覆盖 8 类工具**：Claude Code（含子代理记录）、Codex、Pi、DSH（含新版 `session.v4`）、Antigravity、opencode、Hermes Agent、Kimi Code。原日志已删除、无法读取或来源本身没有正文时会明确说明，不显示为空对话。
- **导出 Markdown**：按当前显示选项导出为 `.md` 文件或复制到剪贴板，包含会话标题、Agent、工作目录、时间、模型与源文件；工具调用以可折叠块呈现，过长输出自动截断并注明。CLI 同步新增 `tt-swift transcript --tool NAME --session ID [--thinking] [--system] [--no-tools] [--lang zh|en] [--out FILE]`。
- **中英文界面**：新功能的界面文案与导出内容均已适配英文。

对话内容只在打开时从原始日志只读解析到内存，不写入用量库或缓存；只有你主动导出或复制时才会保存到你选择的位置。数据库仍为 schema v8，未修改扫描去重规则或公开上传字段。

macOS 安装包采用 ad-hoc 签名，未公证。
