测试版：主窗口改成顶栏导航，新增本机端口页。这是第一个测试版，界面和端口功能都可能再调整。

- 主窗口：去掉侧栏，导航标签放到窗口顶栏中间；时间范围和 Agent 筛选移到内容区顶部。导航的顺序和显隐仍在「设置 › 界面 › 导航」里调整。
- 概览：首屏是一个大数字加趋势图，右侧是各账号配额，点一行直接去看这个账号。热力图只在所选 Agent 范围内统计。
- 账号：改成左边选账号、右边看额度；每个额度窗口一个圆环。读不到额度的账号显示状态，不显示为 0。
- 端口（新增）：列出本机全部监听端口，进程工作目录在某个项目里就归到这个项目。可以打开、关闭端口，在终端里启动或停止项目。结束进程前一律先确认；系统进程、其他用户的进程不提供关闭；「停止项目」不会结束 Agent 自己的进程。启动命令从 package.json、Makefile 等文件识别，识别不了可以手填。
- 状态栏面板：新增「运行中的端口」，显示哪些端口在「设置 › 界面」里选；去掉了「今日各 Agent」，状态栏标题的显示方式只在设置里改。
- 会话详情和活动明细在主窗口内打开，不再弹独立窗口。
- 更新：设置里新增「接收测试版更新」。v0.5.9 及更早版本没有这个开关，需要手动下载安装本测试版；之后的测试版可以在应用内收到。
- 修复首次启动时范围菜单空白，以及包装命令和中断标记被当成会话标题。

端口信息只在本机内存里，不写入用量库，也不进入公开统计。未修改扫描去重规则或公开上传字段。

macOS 安装包采用 ad-hoc 签名，未公证。
