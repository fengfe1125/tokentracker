概览新增全部 Agent 的年度 Token 热力图，并修复切换时间范围时部分统计没有更新的问题。

- 日历按本地日期汇总所有 Agent 的输入、输出、缓存读取和缓存创建 Token，不受侧栏显示设置影响。支持切换年份、悬停与点选每日 Agent 明细。
- 未来日期留空；没有已记录用量的日期显示灰格。可归入同一天的观察区间保留估算标识，无法可靠归入一天的历史量单独说明。
- 时间范围变化统一刷新统计、模型榜与分析数据；快速切换时取消过期查询并丢弃旧结果。加载和读取失败时不再将旧范围的数字显示在新范围下。
- 修复趋势图数据变化后悬停索引可能越界的问题。

热力图仅在本机展示，复用现有每日统计规则；没有新增公开上传字段或修改用量数据库格式。
