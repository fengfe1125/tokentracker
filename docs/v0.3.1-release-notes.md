# TokenTracker v0.3.1

## 简体中文

- 设置 → 通用新增「跟随系统」「简体中文」「English」。默认跟随系统；中文系统使用简体中文，其他语言使用英文。
- 切换后即时更新界面、菜单和详情窗口，保留筛选、选中项与未保存输入；语言选择在重启后保持。
- 英文界面使用 K/M/B 数量缩写及英文日期。中文继续使用原有万／亿偏好，切换语言不改写该偏好。
- 覆盖概览、项目、报告、会话、Agent 活动、账号、上传与更新提示，并调整英文窄窗口布局。
- 语言偏好仅保存在本机 App 偏好中。用量数据库、共享设置格式、扫描和成本计算、公开统计字段均不变。

## English

- Choose System default, 简体中文, or English in Settings → General. Chinese systems default to Simplified Chinese; other systems default to English.
- Switch languages immediately across pages, menus, and detail windows while retaining filters, selections, and unsaved input. The choice persists after restarting.
- English uses K/M/B token abbreviations and localized dates. Chinese retains the existing 万/亿 preference without rewriting it when languages change.
- Translations cover Overview, Projects, Reports, Sessions, Agent activity, accounts, publishing, and update messages, with adjustments for narrow windows.
- The language preference stays in local App preferences. Usage storage, shared settings, scanning, cost calculations, and public statistics fields are unchanged.
