# 指标与时间口径

## Token 与费用

每条事件使用四个互不重叠的字段：`input`（非缓存输入）、`output`、`cache_read`、`cache_write`。所有统计 API 的行新增 `tokens`，等于四项之和；保留原字段。推理 Token 已包含于输出时不额外累加。

估算费用按四项分别乘以共享本地价格目录 `~/.tokentracker/prices.json` 中供应商、模型和事件时间对应的费率，再除以一百万。仓库根目录的 `prices.json` 是旧格式，仅兼容显式模型项；App 与 CLI 使用共享目录。App 每 24 小时检查一次公开供应商价格页，保存来源、获取时间、生效时间和历史版本。缺少精确供应商／模型匹配或观察区间跨越费率版本时保留 Token、费用未计价；不使用通用默认价或子串匹配。Codex 原始 `input_tokens` 含缓存，入库前扣除缓存读写。例如输入 1,000,000、其中缓存读取 800,000，输入 $2/M、缓存读取 $0.2/M 时：`200000 × 2/M + 800000 × 0.2/M = $0.56`。

来源自带的费用优先，包括明确的零费用。`cost_source` 区分费率目录估算、来源提供的估算/实际费用和未版本化历史估算。迁移不以今天的费率追写旧估算。官方页面未标明生效日期时，以首次成功获取时间作为版本生效点；观察快照跨越费率变更时不伪装成精确费用。无法定位时间的费用校准单独保留，不伪装成当天调用费用。

## 三种时间质量

| time_quality | 含义 | 全部历史 | 指定范围 / 趋势 |
|---|---|---|---|
| `exact` | 日志有事件时间 | 计入 | 按事件时间计入 |
| `observed` | 两次累计快照间的差量，区间为 `interval_start` 至 `ts` | 计入，标记估算 | 只有整个区间落在范围或同一分桶时才计入 |
| `unallocated` | 存量无法还原时间，或历史费用校准 | 计入 | 不作为精确用量计入，单独报告 |

观察区间只是“这段时间内发生了变化”，不是逐次请求的准确时间。没有变化的扫描也更新观察边界。累计计数器下降时记录重置，保存旧总量、更新基线；下一轮只计算新基线后的增量。

例如昨天首次观察到累计 1,000，今天 10:00 再次观察仍为 1,000，11:00 变为 1,100：全部历史 1,100，今天 100（观察区间估算），另有 1,000 未分配历史。如果只有昨天与今天两次观察，新增 100 跨日，不声称全部发生在今天，而是在未分配摘要中说明。

一个跨小时但不跨日的区间可以计入当天总量，却不能任意计入某个小时。趋势之和因此可能小于统计总量；界面会显示排除的用量。

## 历史 API 口径（原 Web 服务）

以下路径保留为历史契约说明，当前桌面入口使用原生 Swift 查询。

- `/api/stats`：原 `rows`、`total` 保留；每行包含 `tokens`、`cache_write`、`estimated_tokens`、`unallocated_tokens`。`total.unallocated={tokens,cost,events}` 是当前时间口径无法归入的摘要。
- `/api/daily`：保留 `rows`，新增 `summary`（含 `unallocated`、`estimated_tokens`）；今天按小时，其余按天。
- `/api/models`、`/api/sessions`：统一总 Token 与时间质量计数。纯未分配会话的 `ts`、`last_seen` 可为空，不能解释成 1970 年或今天。
- `/api/session_detail`：显示会话全部历史，并返回 `observation_intervals`；与范围筛选后的列表总量可能不同，界面明确标注。
- `/api/quotas`：窗口保留 `source`，新增 `stale`；本地窗口 `unallocated` 为同 `unit` 的未分配用量，不包含在 `used` / `pct`。用户 `include_cache` 配置保持不变，启用时计入缓存读与写。
- `/api/scan/status`：`running`、`last` 保留；最近一次扫描有 `source`、`started_at`、`finished_at`（Unix 秒）及各工具结果/错误。重置与无法映射的旧来源会在扫描结果中报告。

限定范围的未分配摘要包含“可能属于此范围、但不能确定”的历史，不代表这些用量一定发生在这个范围内。所有界面和状态栏使用后端 `tokens`，避免各自重新计算而漏加缓存。

## 时间范围口径

- 今天：自然日 0 点起。
- **近 7 天**：从六天前本地零点到当前时刻（保留旧 `week` 查询范围，非自然周）。月初可能大于本月，因为包含上月末用量。
- **自然周**：本地时区周一零点至下一周一零点，仅用于周报和自然周预算；跨夏令时时不强行使用 168 小时。
- 本月：自然月 1 日 0 点起。
- 全部：全部历史（含未分配到时间的量）。

## v0.3 分析与导出

`UsageQuery` 显式携带起止时间、时区和工具/项目/模型筛选；区间左闭右开。项目归属以用量事件计算，手动会话归属优先于目录调整，再回退到可靠工作目录的自动身份。无法证明来源的记录归入未归属；各项目与未归属之和应守恒。

“用量记录数”是账本事件数，不能当作模型请求数。“费用合计”紧邻“含估算，非订阅账单”，使用现有 `cost_source`；没有计价的记录单独计数，全部未计价时显示“未计价”。未分配历史不是当前时段确定发生的用量。

预算可以使用总 Token 或估算美元，官方订阅百分比独立。官方预测使用真实抓取时间，要求最近 5 分钟内成功样本、60 分钟内至少四点且跨度至少 15 分钟；缺少可识别重置周期时只显示阈值。账号、窗口、周期变化不能混用样本。

异常检测将今天与过去 14 天相同时刻比较，至少七个有效日，使用中位数与中位绝对偏差。贡献分解使用历史平均值以保持同一维度可加，不能把项目、工具和模型三组贡献相加。覆盖变化或时间未分配时优先显示限制。

周报各部分从同一读取事务获取，保存生成时间、时区及规则版本；后台补扫不修改已有快照。CSV/JSON 导出同样使用独立读取事务和分页；默认项目、会话及自定义调用名称使用单次导出内稳定别名，绝不导出凭据、提示词、参数或输出正文。
