测试版：将「用量 → 项目」占比可视化置顶，新增概览「今天」实时脉冲面板与「本月」月历热力图，补齐 Antigravity 配额与任务提醒，并全面优化滚动与布局性能。

- **项目占比可视化置顶**：将 `项目占比` 环形图与 `项目 Token 构成` 四类堆叠横条图移动至「用量 → 项目」页的汇总指标下方、项目列表上方，打开用量页即可直观查看各项目占比与 Token 构成并点击下钻；`Agent 分布` 与 `模型分布` 保留在项目列表下方，避免异步分析加载或搜索项目名时引起列表跳动。
- **概览「今天」脉冲面板与「本月」月历热力图**：当「今天」活跃小时数 ≤ 2 时，使用趋势区自动展示实时脉冲面板（活跃时段、较昨日同刻对比、24 小时迷你节奏条、四类 Token 构成与今日主要会话，支持一键切到 24 小时固定槽柱图；活跃小时 ≥ 3 时自动切回柱图并标出当前小时）；「本月」Token 热力图改为按自然周（周一至周日）排布的月历网格，宽窗右侧附各周合计与活跃天数。
- **Antigravity 配额与任务提醒**：只读自动识别本机 Antigravity 登录态（macOS 钥匙串 `service=gemini, account=antigravity` 与 Antigravity IDE `state.vscdb`，凭据仅留内存、不落盘且不改写原工具登录态），接入账号页配额卡片、菜单栏配额圆环与刘海 HUD；任务提醒支持通过 `~/.gemini/config/hooks.json` 接入 Antigravity 的 `SessionStart`、`PreInvocation` 与 `Stop`（区分用户取消与正常完成），并支持一键切回 Antigravity。
- **滚动与响应式布局性能优化**：新增 `ScrollActivity` 在滚动期间 O(1) 清理并抑制悬停重绘；以单遍测量的自适应 `Layout` 替代 `ScrollView` 内双重实例化的 `ViewThatFits`；长列表改为 `LazyVStack` 按行圆角渲染并复用日期格式化器，显著降低滚动掉帧。
