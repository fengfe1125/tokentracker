# TokenTracker v0.3.2

## 简体中文

修复双击应用后没有窗口、看起来无法打开的问题。

- 手动启动显示主窗口。
- 再次从 Finder 或 Dock 打开应用会唤回主窗口，包括关闭后隐藏及最小化的情况。
- 登录项和服务启动继续保持后台运行。
- 保留当前页面、用量数据和语言设置。

## English

Fixes the app appearing not to open when launched from Finder.

- Manual launches show the main window.
- Reopening from Finder or the Dock brings the main window forward, including after closing or minimizing it.
- Login-item and service launches continue running quietly in the menu bar.
- Current navigation, usage data, and language preferences are retained.

macOS 14+ · Apple Silicon · Ad-hoc signed; not notarized.
