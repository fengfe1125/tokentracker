# TokenTracker v0.4.0

## 简体中文

新增刘海左侧配额圆环与本地任务提醒，让 Codex、Claude Code 的真实剩余额度和等待审批请求更容易查看。

- **刘海圆环：** 默认显示剩余额度，悬停查看窗口，点击查看官方配额、本地今日 Token 与小时趋势。无有效官方配额时显示暂无数据，不使用本地 Token 推算订阅额度；陈旧数据保留标记。无刘海屏时保留菜单栏入口。
- **任务提醒与审批：** 可选启用本轮回复结束和等待审批提醒；有效请求支持允许一次、拒绝一次、前往原应用。允许前需展开完整请求；超时、断连或退出后交回原工具，不默认允许。命令和参数不进入提醒历史、日志或系统通知。
- **桌面本地任务：** 已验证 Codex 桌面 26.1007.71326（引擎 0.162.0-alpha.17.2）和 Claude 桌面 Code Local 2.37337.1（引擎 2.1.295）的真实事件及原请求允许／拒绝往返。CLI 和桌面分别展示配置状态、事件接收和版本验收记录。其他版本不自动视为已验收。
- **安全接入：** 原生 Swift Helper 使用同用户 Unix Socket。配置修改先预览、备份和合并，保留其他 Hooks，并遵循原工具的正常信任流程。圆环和任务提醒默认关闭。
- **官方价格同步：** 自动同步官方模型价格，设置提供同步状态；费用按匹配价格和证据显示，不将缺失价格当作确定的零费用。
- **开发隔离：** 开发 App 与发行 App 使用独立身份，避免状态栏与本地设置互相干扰。

支持范围为本机 CLI 与桌面本地会话。云端编排、Cloud、SSH、普通 Chat 和 Cowork 不在本次范围内。“前往原任务”采用激活原应用的回退，需要在应用内选择原会话。系统通知需要 macOS 授权；专注模式可能影响横幅展示。

系统通知允许／点击、两款桌面同时等待，以及外接屏、锁屏唤醒、Space 等场景尚未逐项完成实机验收；详见 `docs/task-reminders.md` 与 `docs/notch-hud.md`。Codex 桌面测试由原生任务接口创建本地会话，未把终端 CLI 测试当作桌面验收。

## English

New notch-side quota rings and local task reminders make Codex and Claude Code quota windows and permission requests easier to inspect.

- **Quota rings:** Show remaining official quota by default. Hover for the window, or click for quota details, today's local tokens, and hourly usage. Missing official quota stays unavailable; local tokens never substitute for subscription quota. Stale readings remain marked. The menu-bar entry remains available without a notched display.
- **Task reminders and approvals:** Optional turn-ended and permission-request reminders, with one-time allow, one-time deny, and return-to-app actions. Allow requires expanding the full request. Expiry, disconnection, or app exit returns control to the original tool without allowing by default. Commands and arguments stay out of reminder history, logs, and system notifications.
- **Local desktop sessions:** Real events and original-request allow/deny round trips were validated with Codex desktop 26.1007.71326 (engine 0.162.0-alpha.17.2) and Claude desktop Code Local 2.37337.1 (engine 2.1.295). Configuration, observed events, and version-specific validation are shown separately for CLI and desktop clients.
- **Local integration:** A native Swift helper uses a same-user Unix socket. Hook configuration changes are previewed, backed up, and merged while preserving other hooks and respecting upstream trust. Rings and task reminders are off by default.
- **Official pricing sync:** Synchronizes official model prices and exposes sync status. Cost estimates retain pricing evidence; unavailable prices do not become an exact zero cost.
- **Development isolation:** Separate development and production app identities prevent menu-bar and preference conflicts.

Cloud orchestration, Cloud/SSH sessions, ordinary Chat, and Cowork are outside this release's scope. Returning to a task activates the original application; select the session there. macOS notification permission and Focus settings affect system banners.

Successful system notification delivery/clicks, simultaneous desktop approvals, and physical display/lock/Space scenarios still have outstanding manual validation. See the detailed acceptance documents. Codex desktop validation used native app-managed local sessions rather than CLI sessions launched inside the app.

macOS 14+ · Apple Silicon · Ad-hoc signed; not notarized.
