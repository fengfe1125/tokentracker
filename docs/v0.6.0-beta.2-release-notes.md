测试版：新增 Antigravity 扫描支持、Agent 会话完整元数据与源文件一键跳转，并大幅优化概览页「今天 ↔ 近 7 天」切换流畅度与页面栏视觉体验。

- **新增 Antigravity 支持**：支持扫描 Antigravity 本地对话日志（`transcript.jsonl`）统计 Token 用量，并支持通过 Hook 映射工作区路径；公开统计服务端校验同步纳入 `antigravity` Agent ID。
- **Agent 会话记录增强**：会话列表与详情展示完整时间、工作文件夹、会话 ID、主模型与多模型构成、四类 Token 明细及估算成本，并显示源日志文件路径与一键在 Finder 中定位的跳转按钮。
- **概览「今天 ↔ 近 7 天」丝滑切换**：热力图小时聚合改为单条索引 SQL 并支持多范围缓存与首屏预热，主指标卡片与热力图同帧切换、取消切换闪屏与二次高度跳变；趋势图禁用离散柱形隐式插值并同步 `loadedRange`，底部「数据与风险」不再因切换时间范围而塌陷。
- **界面与设置体验打磨**：主窗口启用 macOS 26+ 原生液态玻璃外观与无分隔线统一标题栏；时间范围、用量标签、下拉筛选与搜索框统一为 30pt 胶囊控件并加入连续滑动动效；重构设置页卡片分组与任务提醒配置项。

端口信息仍只在内存中，扫描与会话元数据均保持本地，不写入或上传 prompt 与文件内容。

macOS 安装包采用 ad-hoc 签名，未公证。
