测试版：重构周报、Agent 活动、本机端口与设置四个模块，消除跨时区重复周报与大量误报推断，补齐端口识别与控制能力，并将设置整合为 5 个清晰分类。

- **周报去重与管理（schema v8）**：周报主键统一为按周一日期生成的规范自然周键（`week:yyyy-MM-dd`），切换时区不再为同一自然周重复生成快照；升级时自动备份并在事务内合并历史跨时区重复周报，周列表按自然周倒序展示，新增 ISO 周次标牌、生成区间实时预览与删除周报。
- **Agent 活动校准与重设计（活动解析 v3）**：Codex 中已收到输出结果的 `response_item` 工具调用晋升为已确认执行（不再误标为未确认推断）；补齐 DSH 嵌套 `tool/result`、Pi 顶层 `toolResult` 与 Antigravity 后继 `GENERIC` 步骤的结果状态与耗时配对；活动页默认展示已确认执行事实，重构 4 项核心指标、点击榜单直达明细，并将能力覆盖说明收敛至底部折叠区，同时严格保留 `exact` / `derived` / `unknown` / `unavailable` 区分。
- **本机端口完善**：解析监听绑定地址（区分仅本机与局域网可达）、完整命令行（仅内存）、内存占用（RSS）与常见开发框架（Vite / Next.js / Wrangler / Uvicorn / FastAPI / Rails 等），支持子进程父目录与命令行路径回退匹配项目；补全 Antigravity / DSH 等 Agent 进程识别；新增搜索、默认过滤系统常驻进程、一键固定到状态栏、项目重启及状态栏面板一键浏览器打开，并修复关闭端口释放确认的轮询竞态。
- **设置结构整合**：将原有 8 个零散分类收拢为 5 类（通用 / 外观与状态栏 / 提醒与集成 / 数据与同步 / 关于与更新），兼容旧分类持久化键；统一管理 Codex / Claude Code / Antigravity Hooks 与变更预览，端口固定移至端口页，默认折叠低频与高级选项。

端口信息仍只在内存中，扫描与会话元数据均保持本地，不写入或上传 prompt 与文件内容。
