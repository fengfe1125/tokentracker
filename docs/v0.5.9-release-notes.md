修复未使用的 OpenCode 会话一直排在会话记录最前，并支持自定义侧栏。

- 会话记录：OpenCode 等累计快照的成本在本地往返时有极小的浮点误差，旧版每次扫描都会写入一条 0 token 事件，把会话的最后时间刷成扫描时刻。现在不再写入这类事件。
- 数据库升级到 schema v7：首次打开时先做一致性备份，再删除已有的 0 token 噪声行，并在 `migration_history` 中按工具记录删除行数与成本合计。Token 与成本总量不变；v0.5.8 及更早版本无法打开升级后的数据库。
- 侧栏：设置中新增「侧栏」，可勾选显示的导航项与 Agent 数据源，拖动调整顺序，并可恢复默认。隐藏 Agent 不影响用量扫描。
